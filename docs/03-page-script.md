# 课程 03 - Page Script（月历网格）

**真正的日历在这里诞生**：课程 02 的静态骨架换成页面脚本绘制的完整月视图 —— 7 列网格、上/下月翻页、今天描边、点击选日。纯 DOM/CSS 工作，还没有 C++ 数据（课程 04 起喂数据）。

DearOreUI 客户端最受限的表面之一 —— 先读「已知坑」。

## 学什么

- `ComponentSpec.body` 放 `std::vector<DomNode>`：末尾一个 `script` 节点承载页面脚本。
- 页面脚本通过 C++ 注入器在 **UI mount 之后立即执行**（`ExecuteScript` 通道）。
- 日历渲染内核（`renderCalendar` + 委托点击 + view 状态），课程 07 会复用它并加事件/时钟。

## 代码位置

- `src/mod/examples/ex03_page_script.h` —— body 构造 + `kPageScript`。

## 成功标识

卡片上：

- 完整月视图：表头 `SUN..SAT`、当月日期对位准确、上月/下月补全格；
- 标题显示 `8 / 2026`（月/年）；**今天描边**（蓝圈 + 淡蓝底）；
- `‹`/`›` 翻页、`today` 按钮回今天；点击日期选中（蓝底白字）。

## 切换方法

`config.json` → `"example": "03"`，重启游戏。

## 已知坑（本客户端实证）

- **注入通道唯一性**：页面 JS **只能**经 C++ 注入器（mount 后 ExecuteScript）进入；DOM `<script>` 节点期望浏览器执行、或 JS 里 `eval()` —— 都会触发引擎异常（`0x40080201`）。
- **输入合成**：引擎不会可靠地从组件状态合成 click。交互一律 `addEventListener` 绑定真实 DOM 元素 + 事件委托。
- **布局原语（本课最重要的实证）**：CSS Grid / Flex 在这台客户端的页面上下文里**不可靠**——第一版日历用 `display:grid` / `flex` 排 7 列，真机渲染时日期数字散落全屏。**改用绝对定位 + 显式像素坐标**（每格 `left=col*38px; top=row*34px`）后网格对位准确。本课与 04–07 的日历全部使用绝对定位布局。
- **原版风格**：页面脚本画的元素用与组件库一致的视觉 tokens（深底 `#21262d`、细边框 `#30363d`、圆角、今天蓝描边、选中蓝底 `#1f6feb`）——脚本 UI 与原生组件观感统一。
- **CJK 未闭环**：中文动态文本的字体加载路径未验证（曾渲染成格子块）。本课及以下日历统一 ASCII/数字内容（英文星期、数字日期、英文事件）。
- **boot 重试**：脚本执行时 DOM 必须已挂载，`boot()` 轮询容器存在（最多 40 次 × 50ms）。
- `DomNode` 字段声明顺序 `tag, style, attrs, text, children` —— 指定初始化器必须按此顺序（否则 W4 告警）。
